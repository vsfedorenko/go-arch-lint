## Reporting a Vulnerability

If you discover a security vulnerability in go-arch-lint, please report it
responsibly.

**Do NOT open a public GitHub issue for security vulnerabilities.**

Instead, please report vulnerabilities by one of these methods:

1. Open a **private** [GitHub Security Advisory](https://github.com/vsfedorenko/go-arch-lint/v2/security/advisories/new).
2. Email the maintainer directly.

Please include the following in your report:

- A description of the vulnerability and its potential impact.
- Steps to reproduce the issue (proof of concept, if possible).
- The version of go-arch-lint you are using.
- Your Go version and operating system.

### Response time

We aim to acknowledge security reports within **72 hours** and to provide a
fix or mitigation within **14 days**, depending on severity and complexity.

## Disclosure

Once a fix is released, we will publish a GitHub Security Advisory with a
CVE assignment (if applicable) and credit the reporter (unless they prefer to
remain anonymous).

## Scope

This policy applies to the go-arch-lint source code hosted at
[vsfedorenko/go-arch-lint](https://github.com/vsfedorenko/go-arch-lint).
Vulnerabilities in third-party dependencies should be reported upstream, but we
also appreciate being notified so we can update our dependencies promptly.
